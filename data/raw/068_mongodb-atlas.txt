Management
Atlas
Programmatic Access
Copy page
You can interact with
Atlas
programmatically to perform administrative tasks or manage your deployments using the following resources.
Atlas Administration API
Programmatically perform administrative tasks on your
Atlas
cluster outside of the Atlas UI with the Atlas Administration API. Atlas Administration API resources add, edit, or delete administrative objects within
Atlas
, including projects, users, and clusters.
You can explore the various endpoints available through the Atlas Administration API in MongoDB's
Postman workspace.
To configure access for the Atlas Administration API, see
Get Started with the Atlas Administration API.
Tip
Learn about the Atlas Admin API.
See the Atlas Admin API Specification.
Atlas Go
SDK
The Atlas Go
SDK
provides platform-specific and Go language-specific tools, libraries, and documentation to help you build applications that interact with
Atlas
quickly and easily using the Atlas Administration API.
Tip
Atlas Go SDK.
Atlas Embedding and Reranking API
The Embedding and Reranking API provides endpoints for accessing Voyage AI's state-of-the-art embedding and reranking models. Use the REST API and available client SDKs to power search and retrieval in your AI applications.
Learn about the Embedding and Reranking API
See the Embedding and Reranking API Specification
Atlas CLI
The Atlas CLI is a command-line interface built specifically for
MongoDB Atlas
. You can use Atlas CLI to interact with
Atlas
from the terminal with short and intuitive commands and accomplish complex operational tasks such as creating a cluster or setting up an access list interactively and programmatically.
Tip
Learn more about the Atlas CLI.
Get Started with the Atlas CLI.
HashiCorp Terraform MongoDB Atlas Provider
HashiCorp Terraform MongoDB
Atlas
Provider provides refined programmatic access and management of
MongoDB Atlas
resources. You can define your environment using the HashiCorp Configuration Language (HCL) and deploy, update, and manage
Atlas
infrastructure as code through HashiCorp Terraform. This allows you to integrate
Atlas
into your continuous delivery workflows.
Tip
Learn more about MongoDB Atlas and HashiCorp Terraform.
Managing IaC with MongoDB Atlas and HashiCorp Terraform
(Video Walkthrough).
Cloud Development Kit for Terraform
CDK
for Terraform leverages the
MongoDB Atlas
Atlas Administration API to enable provisioning across popular programming languages such as JavaScript, TypeScript, Python, Java, Go, and C#. Utilizing the powerful capabilities of Terraform, with
CDKTF
you can now create, manage, and update your
Atlas
resources with ease and deploy them seamlessly in the cloud without context switching from the native programming language of choice.
Tip
MongoDB Cloud Development Kit for Terraform.
Managing IaC with MongoDB Atlas and the Terraform CDK
(Video Walkthrough).

Atlas
CloudFormation Resources helps you to manage
MongoDB Atlas
. It simplifies provisioning and management of
Atlas
features on
AWS
. You can create YAML- or JSON-based templates for the service or application architectures you want and have
AWS
