Section titled “Authentication”
Netlify uses OAuth2 for authentication
authentication
The process of verifying who someone is before letting them access your site.
×
. All requests must use HTTPS
HTTPS
The secure protocol, enabled by SSL, that encrypts data transferred between a browser and your site.
×
.
To generate a personal access token
personal access token
A credential tied to your personal account that lets tools and scripts act on your behalf without your password.
×
(PAT
PAT
Short for personal access token, a credential tied to your personal account.
×
):
Go to
Applications
>
Personal access tokens
.
Select

.
Enter a descriptive name to help you remember what the token will be used for.
Select

to authorize access to your SAML-based team data through the API.
Select an

Select

Copy the token to your clipboard and store it in a safe location. Once you navigate away from this page, you won’t be able to access the value again.
Select

Use your PAT for manual authentication in shell scripts or commands that use the Netlify API.
To authenticate API requests, include the token in the authorization header:
Authorization: Bearer <YOUR_PERSONAL_ACCESS_TOKEN>
To authenticate in shell scripts, refer to the
code sample above
for an example of how to use this token in a curl request.
Password resets invalidate tokens
If you reset your Netlify password, all personal access tokens and OAuth tokens created before the reset will be permanently invalidated. After a password reset, you must
generate new tokens
and update any services or scripts that rely on them.
SAML SSO
If your team requires you to log in with
single sign-on (SSO)
, your personal access tokens will be denied access to the team by default. You can choose to grant access to the team when you generate a new token. You must be logged in to the team with SSO to grant access to it.
If you’re making a public integration with Netlify for others to enjoy, you must use OAuth2. This allows users to authorize your application to use Netlify on their behalf without having to copy/paste API tokens or touch sensitive login info. You’ll need an application client key and a client secret
secret
Sensitive credentials, like passwords and API keys, that must be kept private.
×
to integrate with the Netlify API. You can register a new application in your Netlify user settings for
OAuth applications
. Visit our blog post on
integrating with Netlify
for more information including common grant types and an example project.
The OAuth2 end-user authorization endpoint is
https://app.netlify.com/authorize
.
Rate limiting
Section titled “Rate limiting”
To protect Netlify from getting flooded by automated deploys or misbehaving applications, the Netlify API is rate limited.
You can make up to 500 requests per minute for most requests.
